Key Research Distinction

Standard college datasets describe built facilities and their permanent structural capacities. A machine learning model predicting Total Parking Spaces models the capacity scale of facilities, not real-time open spots.

  • Structural Capacity: What this project models based on property features.
  • Dynamic Occupancy: Requires real-time IoT gate sensors or camera feeds.
