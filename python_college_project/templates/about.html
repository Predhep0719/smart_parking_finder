About the Project

Academic documentation and architecture of Smart College Parking Space Finder.

1. Problem Statement

Colleges and institutional complexes frequently struggle with parking congestion, inefficient resource allocation, and inadequate infrastructure planning. Facility administrators often lack empirical statistical benchmarks to anticipate how many parking bays a property requires based on its status, building type, ownership structure, and urban geography.

2. Project Aim

To build an end-to-end data analytics and machine learning system that ingests historical institutional parking records, evaluates the structural determinants of parking scale, trains a non-linear regression ensemble model, and predicts facility capacity to assist in campus planning and urban management.

3. Machine Learning Pipeline Architecture
Data Preprocessing Data normalization, categorical string casing, validation of non-negative integers for spaces, missing value checking, and deduplication audit.
Feature Encoding Scikit-learn OneHotEncoder(handle_unknown='ignore') in a ColumnTransformer to avoid data leakage while handling new cities/categories during live inference.
Model Selection RandomForestRegressor (100 decision trees) leveraging bagging (bootstrap aggregating) to handle non-linear combinations of categorical features.
Validation Metrics 80/20 train/test split evaluated using MAE, MSE, RMSE, and R² variance explained (avoiding classification accuracy misapplications).
4. Current Limitations & Real-Time Boundary

Historical CSV dataset records describe the installed structural capacity of sites. While machine learning effectively identifies typical parking requirements for given facility attributes, historical data alone cannot predict live vacancy without physical hardware.

5. Future Scope & Hardware Integration
  • Ultrasonic / Geomagnetic Sensors: In-ground IoT sensors reporting spot occupancy over LoRaWAN or MQTT.
  • Edge Computer Vision: YOLO-based parking lot camera feeds counting vacant stalls.
  • Gate Telemetry: Automatic barrier RFID/ANPR scanners computing Available = Capacity - Occupied in real time.
Technology Stack
  • Language: Python 3.10+
  • Framework: Flask
  • Data Analysis: Pandas, NumPy
  • Machine Learning: Scikit-learn (RandomForestRegressor)
  • Frontend: HTML5, CSS3, JavaScript, Bootstrap 5
  • Storage: Direct CSV ingestion (No DB required)
Dataset Specifications
