Understanding Regression Metrics in Simple Plain Language

Why not "Accuracy %"? Classification models classify discrete classes (like Dog vs Cat) where predictions are either right or wrong. Parking capacity is a continuous numeric quantity (from 0 to 1,688 spaces). An error of 2 spaces on a 100-space lot is a very close estimate, so standard regression distance metrics are required instead of binary accuracy.

MAE (Mean Absolute Error): Measures the average magnitude of prediction errors in actual parking spaces. If MAE is 35, the model's prediction is, on average, within ~35 spaces of reality.

RMSE (Root Mean Squared Error): Squares each error before averaging and then takes the square root. Because errors are squared, RMSE penalizes outlier predictions heavily.

R² (Variance Explained): Ranges up to 1.0. An R² around 0.40–0.60 indicates that the property type, status, and geographical city features explain a substantial portion of structural capacity variations across facilities.
